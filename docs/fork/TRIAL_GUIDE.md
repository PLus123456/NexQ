## 这一版有什么

| 方面 | 内容 |
|---|---|
| 界面 | 全中文，托盘菜单也是；设置 → 通用 可以切 English，两个窗口同时变 |
| AI 模型 | 设置 → AI 模型：可以建多个连接，23 个模板（OpenAI 兼容、DeepSeek、硅基流动、Ollama、LM Studio、Anthropic、Gemini、OpenRouter、Claude 订阅等）。Base URL 原样使用，不自动加 `/v1`，输入框下面显示实际请求地址；模型 ID 可以手填；Key、请求头、兼容选项（temperature、思考）都能改。任务路由：实时翻译、会议总结、每个 AI 动作可以各用各的连接和模型。AI 回答语言默认跟随界面语言。点底栏的 AI 芯片可以快切模型。后端去掉了全局锁，实时翻译和 AI 助手能同时出字 |
| 语音识别 | "我"和"对方"分别选引擎和识别语言。新引擎：Soniox（实时字幕，可以顺带单向或双向翻译；一条连接满 290 分钟会在句子间自动换新连接；v5 的断句灵敏度可调）、远程 Whisper（OpenAI 兼容接口，跑在你别的机器上；服务器跟不上时先合并分段，不轻易丢音频）。新预设"自建 Whisper"：两路都用远程 Whisper。本地 Whisper.cpp 可以开 Metal GPU |
| 翻译 | LLM 翻译用"实时翻译"任务的连接和模型，提示词和术语表可改；DeepL / 微软 / 谷歌的地址可改；目标语言可以手填代码；可以只翻"对方"；Soniox 的译文直接上字幕，不再翻第二遍。翻译设置左栏最上面是"Soniox 边识别边翻译"卡片：某一路点"改用 Soniox 识别并翻译"就一次切好，没填 Soniox Key 会提示去填 |
| 个人知识库 | 设置 → 上下文策略 → 个人知识库：embedding 端点自定义（地址、Key、模型、维度）；单独的 `rag.db`；int8 精确向量索引加中文关键词混合检索；按内容哈希增量索引，改了文档只重算改动部分；换模型会提示重建，重建完成前只走关键词 |
| 首次设置 | 六步：语言、AI 模型、语音识别、翻译、音频测试（含系统音频和权限指引）、完成页（开会前检查）。中途退出，再打开从断点继续；设置 → 通用 里可以重新运行 |

## 验收清单

1. 打开后是中文的首次设置，一路做完（或跳过）进主窗口。
2. 主窗口、设置、悬浮窗、托盘都是中文；切到 English 立即生效，两个窗口同时变。
3. 设置 → AI 模型 → 添加连接 → "自定义（OpenAI 兼容）"：Base URL 填你那个不是 `/v1` 的地址，看"实际请求地址"对不对；模型名手填；"测试对话"通过；开会时 AI 助手能流式回答。
4. 故意填错 Key：显示 401 原始错误和实际请求地址。
5. 任务路由：实时翻译选快模型、会议总结选强模型；开着实时 LLM 翻译时点 AI 助手，两边同时出字。
6. 会议音频：我 = 中文、对方 = 英文（或自动检测），各自生效；对方用 Soniox，字幕和中文译文实时出来；我用另一台机器上的远程 Whisper，能出字。
7. 翻译目标语言手填一个代码（例如 `ja`）能用；可以只翻"对方"；AI 调用日志里每句只翻一次。
8. 本地 Whisper.cpp 开 GPU 后明显比关掉快。
9. 知识库配好 embedding 端点，上传文档建索引；改过的文档重新上传后只重算改动部分（进度里显示"复用 N 块"）；中文问题能检索到。
10. 首次设置里"上传简历"能打开知识库面板；中途退出再打开能接着做。
11. 用 Claude 订阅的话：Mac 上"登录"按钮能打开终端。
12. 官方 NexQ 的数据目录 `~/Library/Application Support/com.nexq.app` 和钥匙串里的 `NexQ:*` 没变。
13. （可选）现场会议：一路音频用 Soniox，翻译选"双向"、两个语言填中文和英文，每句话按自己的语言翻成另一种（这项还没用真 Key 测过）。

## 2026-11-02 修复

- **中文问题检测：** 后端和前端备用检测都支持全角问号、中文分句、常见简繁体问法，以及“请解释”等面试提问。仍是规则检测，隐含问题或修辞问句需要人工判断。
- **中文导出文件名：** 保留中文等 Unicode 字符，过滤路径分隔符和文件名禁用字符，并限制文件名长度。
- **中文词数：** 实时统计、会议详情和说话人时间轴统一使用语言分词；旧 WebView 不支持分词接口时按中文字数回退。最终字幕被修正、缩短或改归说话人时会同步校正统计。
- **会议音频热切换：** Soniox 设置与跟随全局目标的翻译语言变更，会在设置同步完成后重启识别。切换过程中继续编辑不会漏掉最后一次设置；结束会议时取消尚未执行的重启；旧会议的延迟回调不会停止新会议。识别引擎初始化失败时会关闭已打开的设备，保留会议录音状态供修正配置或结束使用。
- **结束时的最后一句：** 等待识别任务及字幕转发结束后再保存会议。远程 STT 最多等待服务器 5 秒，另留最多 2 秒转发末句；原生采集任务整体共用 10 秒结束预算。Soniox 换连接期间结束时，会用最后一条连接发送已排队的音频。Web Speech 也会先停止收音并等待末句，从悬浮窗结束时会与主窗口确认。
- **思考参数：** 原来按厂商一键填入的按钮改为只读“查看思考参数示例”，不会自动修改请求。需要按具体模型的接口文档核对后手工填写额外 JSON。
- **AI 任务并发：** 实时助手、会议总结、待办提取、书签建议和会议问答不再共用一个全局占用标记。每个请求独立取消；切换会议或离开页面会停止该页面的请求，迟到的结果不会写进另一场会议。
- **预设与快捷键提示：** 音频预设显示缺少的 Key、模型或服务器地址；未就绪时应用会提醒。快捷键注册失败会显示处理建议，同时修复换键和卸载时异步注册遗留的问题。

## 补充验收

1. 使用“这个方案可以吗？”、“为什么这样设计”、“請解釋這個方案”等中文输入检查自动问题检测；英文问题仍应正常触发。
2. 将会议命名为“周会讨论”，导出文件名应保留中文；中英文混合发言有合理词数，同一条最终字幕修正后统计不重复累加。
3. 会议中使用 Soniox，修改模型、断句参数或跟随全局的翻译目标；确认重新连接后使用最新配置。连续修改两次，再在切换过程中结束会议，确认没有重新开始收音。
4. 同时启动实时助手和历史会议总结，分别停止其中一个；另一项继续。切换历史会议时，旧任务的结果不应出现在新会议里。
5. 无 Key、无本地模型或远程地址留空时，检查预设按钮的缺项提示。查看思考参数示例后，额外 JSON 应保持原值。
6. 结束前说最后一句，检查会议记录包含它；远程服务器不响应时确认有超时提示。Soniox 换连接时结束的排队音频路径已用本地 WebSocket 模拟测试覆盖，真实服务仍需验收。

## 剩余限制

- 模型是否支持关闭或降低思考由服务端决定。手工保存的不兼容参数仍可能返回 400；本次不会自动删除用户已有 JSON。
- 实时回答面板仍一次显示一个 AI 动作；同一场会议同一任务不会重复启动。Claude 订阅中共用同一个会话的任务仍顺序执行，HTTP API 或独立会话可并发。
- 网络断开、服务器长期不响应或结束等待超时，仍可能缺少最后一句；程序会有界停止，不能保证服务器返回未完成的识别结果。
- 外部程序占用的 `⌘⇧H` 不能由本 App 释放。若仍注册失败，在 设置 → 快捷键 换一个组合，或退出占用它的程序。
- 本轮只在 macOS 环境构建和测试，未提供 Windows 安装包。
